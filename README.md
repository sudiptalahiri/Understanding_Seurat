# Understanding Seurat

This project is designed to understand the Seurat single-cell RNA-seq
analysis workflow from both a biological and computational perspective.

## Analysis workflow

1. Create Seurat object
2. Quality control
3. Normalization
4. Highly variable features
5. Scaling
6. PCA
7. Nearest neighbors
8. Clustering
9. UMAP
10. Marker identification

## Learning objective

For each Seurat function, understand:

- What problem it solves
- What input it requires
- What mathematical operation is performed
- What output it produces
- How the Seurat implementation works
- What assumptions are being made
